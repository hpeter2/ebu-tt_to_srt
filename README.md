This script converts an XML in EBU-TT-D-Basic-DE format to an .ASS-Subtitle file, that can be read by Media Players

## Usage:
This script converts all XML-files in the current directory and all its subdirectories.

```sh
$ python ebu-tt_to_srt.py
```

## Format specification:
[XML-Format für die Distribution von Untertiteln in den ARD Mediatheken (EBU-TT-D-Basic-DE)](https://www.ard.de/die-ard/EBU-TT-D-Basic-DE-XML-Format-fuer-die-Distribution-von-Untertiteln-in-den-ARD-Mediatheken-100.pdf)
